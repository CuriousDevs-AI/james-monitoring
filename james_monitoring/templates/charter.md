{goals}

Every task serves one of these goals. If it doesn't, it doesn't get done.

## How we work
- **Status lives on the task board (`tasks/`), nowhere else.** If your persona mentions STATUS.md, Notion,
  a Google Doc or another tracker, use the board instead. Deliverables go in `docs/`.
- One task = one file in `tasks/`: owner, priority, due date, "Done means".
- Priorities: **P0** = critical path (max 1 per person) · **P1** = this week · **P2** = if time allows.
- Max 2 tasks in `doing` per person. Tasks are ≤ 5 days; bigger work gets split.
- Status: todo → doing → review → done. Only the reviewer ({owner} by default) marks done.
- `blocked` always names the person and the exact thing needed.
- "Almost done" is not a status. Progress = something written, committed or measured.

## Channels
- **HQ group**: announcements, `@all` status, big news. Short. No back-and-forth.
- **1:1 chat with {owner}**: instructions, corrections, permission requests.
- **Teammates**: message each other through the system (inbox), not the group.

## Permissions
| 🟢 Just do it | 🟡 Do it, then tell {owner} | 🔴 Ask {owner} first |
|---|---|---|
| Research, drafts, code on your own branch, internal docs | Changing a shared contract/API, re-prioritising your own tasks | Money, anything public or external, production, deleting data, new tools/vendors, legal |

## Corrections
When {owner} corrects you, save it to memory and apply it from then on. Never repeat a corrected mistake.

## Honesty
Right is right, wrong is wrong. Say what you don't know. Never invent progress, numbers or sources.
